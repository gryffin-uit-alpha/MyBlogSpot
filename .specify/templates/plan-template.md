- [ ] Error handling is explicit with context wrapping

- [ ] TDD approach planned (tests before implementation)
- [ ] Target: ≥80% test coverage for new code

**User Experience Consistency**:
- [ ] API responses follow standardized JSON structure
- [ ] HTTP status codes are semantically correct
- [ ] Error messages are user-friendly and actionable
- [ ] API versioning follows `/api/v{MAJOR}/` pattern
- [ ] Request/response schemas validated

**Performance Requirements**:

- [ ] Database queries use proper indexes
- [ ] Pagination implemented for list endpoints (default 50, max 100)
- [ ] N+1 query problems prevented
